# 원스텝 워크플로우 보드 — PC ↔ 폰 자동 동기화 (웹판)

원래 `4_원스텝_워크플로우_보드.html`(단일 파일)에 **클라우드 자동 동기화**를 붙인 웹판입니다.
보드 기능·화면·데이터는 원본 그대로이고, 저장 위치만 "내 브라우저"에서 "내 GitHub 비공개 저장소"로 넓혔습니다.

| | 원본 HTML | 이 웹판 |
|---|---|---|
| PC에서 수정 | PC에만 저장 | 1~2초 뒤 GitHub에 자동 업로드 |
| 폰에서 열기 | 파일을 폰으로 복사해야 함 | 같은 주소만 열면 최신 내용 표시(최대 6초 지연) |
| 폰에서 수정 | 폰에만 저장 | PC가 6초 안에 자동으로 받아감 |
| 서버 비용 | 0원 | 0원 (GitHub 무료) |

- 저장 파일은 **비공개 저장소의 `board.json` 한 개**입니다. 고객명·연락처·견적가·계좌번호가 들어 있으므로 **반드시 비공개 저장소**를 씁니다.
- GitHub 토큰은 **각 기기 브라우저(localStorage)에만** 저장되고, 코드·서버·채팅 어디에도 들어가지 않습니다. 통신은 `api.github.com` 한 곳뿐입니다.

## 처음 한 번만 (약 3분)

### 1) 비공개 저장소 만들기 (PC 권장, 30초)
1. https://github.com/new
2. Repository name: `onestep-workflow-data`
3. **Private** 선택 → `Add a README file` 체크 → **Create repository**

### 2) 토큰 발급 (1~2분)
1. https://github.com/settings/personal-access-tokens/new
2. Token name: `onestep-board`
3. Expiration: `1 year` (만료되면 새로 발급해 다시 넣으면 됩니다)
4. Repository access → **Only select repositories** → `onestep-workflow-data` 선택
5. Permissions → Repository permissions → **Contents: Read and write** (이것만)
6. **Generate token** → `github_pat_...` 복사

> 더 간편한 방법을 원하면 **비밀 Gist** 모드도 있습니다. 이 경우 classic 토큰에서 `gist` 권한만 체크하면 되고, 저장소를 만들 필요가 없습니다. 단 **사진이 많아 데이터가 1MB를 넘으면 동작하지 않고**, 링크를 아는 사람은 읽을 수 있습니다. 개인정보가 들어가는 보드에는 저장소 모드를 권합니다.

### 3) PC에서 연결
1. 아래 주소를 엽니다 → 오른쪽 위 **☁️ 동기화** 클릭
2. 저장 방식: **① GitHub 비공개 저장소**
3. 토큰 붙여넣기, 아이디 `smile697900`, 저장소 `onestep-workflow-data`, 경로 `board.json`
4. **🔗 연결하고 저장** → "✅ 연결 완료 — 이 기기 기록을 올렸습니다" 확인

### 4) 폰에서 10초 만에 연결
1. 폰에서 같은 주소를 엽니다 → **☁️ 동기화** 클릭
2. **⚙️ 설정 코드 붙여넣기** → PC에서 **[⚙️ 설정 코드 복사]** 로 복사해 둔 코드를 붙여넣기
   (카톡 '나에게 보내기'·메모 등 본인만 보는 곳으로 옮기세요. 코드에는 토큰이 들어 있습니다.)
3. 끝 — 폰에 PC의 최신 보드가 자동으로 나타납니다.

> 토큰을 직접 입력해도 됩니다(같은 토큰을 두 기기에서 함께 사용 가능).

폰 홈 화면에 추가: Chrome 메뉴 → **홈 화면에 추가** → 앱처럼 전체 화면으로 열립니다.

## 쓰는 법

- 평소처럼 보드를 쓰면 됩니다. 카드를 저장하면 **1~2초 뒤 자동 업로드**.
- 다른 기기의 변경은 **6초마다** 확인해 자동 반영하고, 반영되면 `📱 다른 기기에서 바뀐 내용을 불러왔습니다` 토스트가 뜹니다.
- 편집 창이 열려 있거나 입력 중일 때는 **절대 자동으로 덮어쓰지 않습니다.** 창을 닫으면 그때 반영됩니다.
- 두 기기가 같은 시간에 고쳤다면 **나중에 저장한 쪽이 이깁니다.** 덮어쓰기 직전 상태는 앱 내부 자동 백업(💾 백업/복원)에 남습니다.
- 수동 제어: ☁️ 동기화 창의 **⬆ 지금 올리기 / ⬇ 지금 내려받기**.

### 동기화되지 않는 것
- **첨부파일(카드에 붙인 PDF·원본 사진)**: 기기 저장소(IndexedDB)에만 있습니다. 카드에 넣은 사진(썸네일)은 보드 데이터에 포함되어 함께 동기화됩니다.
- 보드는 100MB까지 가능하지만, 사진이 아주 많으면 업로드에 몇 초 걸릴 수 있습니다.

### 웹판에서 달라진 점 (원본 HTML 대비)
- **입금 계좌 문구**: 공개 코드에 계좌번호를 넣지 않습니다. ☁️ 동기화 창의 **🏦 입금 계좌 문구**에서 한 번 입력하면 그 기기에만 저장되고, **[⚙️ 설정 코드]**에도 함께 담겨 폰으로 옮겨집니다. (⚠️ 저장소 `board.json`에는 들어가지 않습니다 — 한 기기에서는 그 기기에서만 보입니다.)
- **자동 파일 다운로드(2분마다 JSON 저장) 끔**: 클라우드 동기화 + 앱 내부 자동 백업이 대신합니다. [📥 지금 백업]은 그대로 동작합니다.
- **PC 폴더 자동저장(실행.bat) 안내 숨김**: 웹 주소로 열기 때문에 해당 없음.

### 문제가 보일 때
| 증상 | 조치 |
|---|---|
| ⚠️ 동기화 오류 | ☁️ 동기화 → 상태 줄의 메시지 확인. 토큰 만료(1년)면 새 토큰 발급 후 다시 넣기 |
| "저장소를 찾지 못했습니다" | 저장소 이름·아이디 오타 확인, 토큰의 Repository access 에 그 저장소가 들어있는지 확인 |
| "권한이 없습니다(403)" | 토큰 Permissions → Contents: Read and write 인지 확인 |
| 폰이 계속 옛날 화면 | ☁️ 동기화 → **⬇ 지금 내려받기** |
| 회사·공용 PC | 쓰고 나서 **연결 해제** (토큰 삭제). 보드 내용은 그 기기 브라우저에 남으므로 함께 정리 |

## 이 폴더의 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 보드 본체 (원본 4_원스텝_워크플로우_보드.html + 동기화 UI 3곳 삽입) |
| `sync.js` | 동기화 엔진 (GitHub 저장소/Gist 읽기·쓰기, 리비전 충돌 방지) |
| `app-sync.js` | 보드 앱과 엔진 연결 (saveData 후크, 6초 폴링, UI) |
| `tests/` | 자동 테스트 (목 GitHub 서버로 PC↔폰 양방향 검증) |
| `deploy.sh` | GitHub Pages 배포 스크립트 |

## 배포 정보

- 주소: **https://smile697900.github.io/images/**
- 리포지토리·브랜치: `smile697900/images` 의 **`gh-pages`** 브랜치만 사용 (`main`·기존 이미지 파일은 손대지 않음)
- 재배포: `./deploy.sh smile697900/images gh-pages --force` (스크립트가 `?v=타임스탬프`를 자동 갱신해 캐시 문제를 막습니다)
- 되돌리기: GitHub → Settings → Pages → 사이트 삭제, 그리고 `gh-pages` 브랜치 삭제
